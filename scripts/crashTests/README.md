# Краш-тесты (headless)

Запускают настоящую физику игры (`src/physics.ts`, `src/nodeBeamPhysics.ts`, `src/damageModel.ts`) в Node, без браузера.

- `harness.ts` — мир, создание машин/стен/пропов, симуляция, запись кадров. Виртуальные часы (`performance.now`) и seed для `Math.random`.
- `analyze.ts` — метрики: пик/среднее замедление (две шкалы), длительность импульса, смятие по зонам, отскок, работа смятия.
- `run_matrix.ts` — матрица сценариев: `npx tsx scripts/crashTests/run_matrix.ts out.json`.
  Переменная `CRASH_SRC=<путь к src>` прогоняет ту же матрицу на другой копии кода (A/B).
- `repro_pole_ab.ts` — воспроизведение бага с круглыми пропами (столб ЛЭП проходится насквозь).
- `repro_lateral_slide.ts` — боковое скольжение без курса гасится за миллисекунды.
- `repro_momentum.ts` — импульс и энергия сразу после удара машина–машина.

Шкалы: 1 px/s = 0.225 км/ч (как в HUD), 1 px = 0.105 м (как в damageModel). Метрики считаются в обеих шкалах (`hud` / `geo`), потому что они расходятся в 1.68 раза.
